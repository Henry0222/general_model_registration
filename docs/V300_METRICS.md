# 3.0 几何路线的连续误差

以下为 2026-09-15 已封存、独立审计的几何内核面板结果，不是本次界面修改产生的新算法收益。成功条件为中心误差 <0.01 mm 且角度误差 <0.05°。

主面板共 536 例：A 领域 402 例全部可计算，B 领域 134 例中 117 例可计算；17 个缺失继续计入严格成功分母，连续统计使用可计算样本。用户小面板 26 例全部可计算，但只含一个独立来源。此处原版初值是困难面板的冻结起点，不代表 2.0 在一般数据上的准确率。

## 解释与证据

产品界面里的 RMS、均值、中位数、P95 与最大距离来自双向采样的最近表面距离，含义不同于本报告的真实中心 / 角度误差。推理不读取真值、真实对应、稳定掩码或生成标签。

上述统计源于本地冻结归档 local_v300_20260915T113844 的 PORT_SUMMARY.json、PORT_CASE_METRICS.json 与 PORT_PAIRWISE.json。逐例重算 480 项连续汇总，最大差异为 1.11e-16；文件完整性与复现范围见 [验证记录](V300_VALIDATION.md)。本仓库不包含原始研究网格和全部逐例产物，不能将这些汇总视为已有外部盲测。
