General Model Registration v3.0.0
=================================

当前本地源码版尚未生成 EXE；运行源码目录的 run_app.bat。
以下为将来便携发布包的使用说明。

1. 完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 GeneralModelRegistration-v3.0.0.exe。
3. 选择一个固定 STL、一个或多个浮动 STL 和结果根目录；也可从资源管理器拖入。
4. 可使用每个模型后的“3D / 选区”划定配准主导区、透选、删除工作副本面片和清理浮动面片；有选区时，最终变换优先满足选区，低覆盖率只降低可信度而不自动回退全模型。
5. 如有需要，为固定或浮动模型勾选“翻转面朝向/法线”。原始 STL 不会被修改。
6. 类骰子、法兰等存在多个相似粗姿态的模型，可启用“彻底检查可能朝向”（速度较慢）；普通模型保持关闭。
7. 按列表顺序完成配准后，检查可信度、日志和三维连续偏差色图。
8. “查看既往配准记录”可以直接打开已有结果，不会重新运行配准。
9. “配准路线”默认自动选择（实验），也可选择原版、A、B 或 A/B 对比。A/B 候选需复核，查看结果时可切换候选。有人工选区时保留选区配准。
10. 高级参数可展开设置；结果区可查看各候选的 RMS、平均距离、中位数、P95 和最大表面距离（mm）。表面距离不等于真实位姿误差。

系统要求：Windows 10/11 64 位。
程序为纯 CPU 计算，不要求 CUDA 或独立显卡。

算法自动寻找共同表面；共同证据不足时尝试整体形状拟合，并降低可信度。结果仅用于几何分析，不构成医学诊断、治疗建议或准确度保证。
选区应尽量包含多个方向或曲面特征；单一平面可能无法约束全部刚体自由度。

请勿向公开仓库或 Issue 上传真实患者、客户或个人数据。
结果日志包含输入文件名和路径，转发结果文件夹前请先检查隐私信息。
