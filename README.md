# General Model Registration

General Model Registration 是一个面向 Windows 的纯 CPU 三角网格刚性配准工具。它将一个或多个浮动 STL 按顺序、相互独立地移动到同一个固定 STL 坐标系，并输出刚性变换、配准后的 STL、连续偏差色图、日志和质量报告。

当前源码版本：**v3.0.0**。先按源码安装步骤更新依赖，再运行本目录的 `run_app.bat`。

3.0 加入 A（局部共同表面）和 B（连续表面偏差）几何后级，以及候选对比和实验性自动选择。桌面界面按用户选择默认启用自动路线；公共 API 的 `AlignmentConfig()` 仍默认原版 2.0，以兼容已有调用(https://github.com/Henry0222/mandible_registration )。自动路线仍属实验功能，A/B 可能使正确位姿退化，原版结果始终可供复核；有人工选区或原版质量失败时跳过后级。使用方式、验证边界和耗时说明见 [3.0 说明](docs/V300_REFINEMENT.md)。

主界面按模型、路线、结果分区，高级参数默认折叠。结果表显示 RMS、P95 与耗时；数值明细可切换原版和 A/B 候选，查看 RMS、平均距离、中位数、P95 与最大距离（mm）。这些是表面距离，真实中心和角度误差须在有真值的独立评估中计算。

3.0 的具体中心 / 角度误差、中位数、P90、尾部与正确初值保持结果见 [数值报告](docs/V300_METRICS.md)；回归与移植验证见 [验证记录](docs/V300_VALIDATION.md)。

2.0 默认启用全阶段候选保留与统一评价、多尺度特征、平面结构候选和共同表面精化。每条精化分支都保留父姿态，避免末级拟合覆盖已有好解；共同表面证据不足时输出带警告的整体形状候选。它仍是启发式搜索，不保证找到数学上的全局最优解。

算法与限制见 [ALGORITHM.md](docs/ALGORITHM.md)。有金标准实验以 [六自由度与矩阵报告](docs/V200_MATRIX_REPORT.md) 为主；本轮 18 组实验、辅助 P95 和启动诊断见 [V200_TEST_REPORT.md](docs/V200_TEST_REPORT.md)。

## 主要功能

- 多尺度 FPFH、FGR / RANSAC、PCA 和平面结构候选。
- 可选的彻底朝向检查：枚举 24 个合法 PCA 轴姿态，并为近似轴对称模型补充绕轴候选。
- 多尺度鲁棒 point-to-plane ICP 精配准。
- 每个入围姿态分别进行多尺度 ICP、共同表面精化和可选 GICP；使用固定评价采样与固定分母择优并保留已有姿态。
- 只估计旋转和平移，不进行缩放或非刚性变形。
- 生成基于目标三角面法向的有符号表面偏差图。
- 一个固定 STL 与多个浮动 STL 的顺序批处理。
- 从 Windows 资源管理器拖入 STL 或输出目录。
- 配准前在内存中翻转任一模型的三角面朝向和法线，不修改原文件。
- 固定和浮动模型的自由套索选区，支持透选、Ctrl 取消、反选、有界组件和选区主导配准。
- 有选区时，以选区覆盖率、中位误差和 P90 决定最终刚体变换；完整模型只负责粗定位和灾难性错位检查。
- 低选区覆盖率会降低可信度并写入警告，但不会仅因低于固定阈值而自动回退全模型。
- 非破坏性面片删除与浮动小组件清理，原始 STL 保持不变。
- 质量门控失败后仍可查看明确标记的最佳候选位姿。
- 连续色阶和局部偏差标注。
- 扫描或导入既往结果，在不重新配准的情况下打开三维结果。
- `align_MMDDHHmm` 自包含结果目录、逐模型日志和失败记录。
- 输出机器可读的 JSON 质量指标和警告。

## 使用方法

1. 选择固定/参考 STL，它在整批配准过程中保持固定。
2. 选择浮动模型数量，并按顺序选择或拖入各个 STL。
3. 可点击每个地址后的“3D / 选区”查看模型、划定配准主导区或编辑工作副本；有选区时，软件将优先满足该区域，而不是让大面积改变的其他表面否决它。
4. 仅在确有需要时勾选对应模型的“翻转面朝向/法线”。
5. 对具有多个相似粗姿态的类骰子、法兰等模型，可启用“彻底检查可能朝向”；角度步长越大，绕轴搜索越快但越粗。普通模型保持关闭。
6. 选择“几何精修”模式（默认原版）、结果根目录和偏差参数，点击“开始顺序配准”。
7. 单个浮动模型失败不会阻止后续模型；可从日志查看失败原因。
8. 在结果列表中查看三维结果、日志或批次目录。有 A/B 对比候选时，可选择候选并分别打开窗口复核。
9. 使用“查看既往配准记录”扫描 `align_*`、导入旧版 `results.json`，或手动查看固定 STL 与已配准 STL。

不要求人工标记共同表面。有足够几何证据时，算法自动寻找共同表面；不足时尝试整体形状拟合并明确降低可信度。低重叠、重复几何、严重缺损、单位错误或网格质量问题都可能使配准不唯一或不可靠；内部拟合分数不能证明真实位姿准确。

选区应尽量包含操作者认可的稳定对应表面，并覆盖多个方向或曲面特征。若固定和浮动模型均有选区，软件执行选区对选区配准；若只有一侧有选区，则在另一侧完整模型中寻找对应区域。单一平面或面片过少可能无法约束全部六个刚体自由度，此时会明确警告并保留安全基线。

## 输出文件

- `fixed_target_used.stl`：实际参与该批次配准和历史查看的固定模型。
- `fixed_target_edit_state.json`：固定模型使用的选区和工作副本编辑状态（存在编辑时生成）。
- `batch_results.json` / `batch.log`：整批结果清单和人类可读日志。
- `aligned_current.stl`：已经变换到固定坐标系的浮动模型，保留输入时的面朝向；勾选“翻转法线”仅影响计算和结果查看，不会把翻转写入这个 STL。删面编辑仍保留。
- `comparison_colormap.ply`：保存逐顶点颜色的偏差图。
- `transform.json`：4×4 刚性变换矩阵。
- `results.json`：配准指标、距离统计、门控决策、耗时和警告。
- `moving_model_edit_state.json`：浮动模型使用的选区和工作副本编辑状态（存在编辑时生成）。
- `registration.log`：输入摘要、法线处理、参数、变换、误差和门控说明。
- `failure.json`：失败任务的结构化错误记录。
- `candidates/<方法>/results.json`：可选模式保留的其他候选及其完整网格、色图、矩阵和质量指标。
- `cancelled.json`：主动取消及最后计算阶段；取消不会记录为配准失败。

质量门控失败但仍得到有限候选位姿时，会改用 `best_candidate_*_FAILED_PREVIEW_ONLY` 文件名输出仅供检查的 STL、PLY 和变换，并在 `results.json` 中标记 `review_only: true`；这不代表配准通过。

上述 STL 面朝向规则同样适用于 A/B 对比候选和失败预览。固定模型归档 `fixed_target_used.stl` 与彩虹图 PLY 保留计算时的方向，以便复核偏差正负。已有导出文件不会自动改写，需要重新运行导出。

有符号距离以固定 STL 的最近三角面法向为唯一基准。固定模型被翻转时，偏差正负方向也会随之改变。彩虹图表示配准后浮动 STL 相对固定 STL 的表面偏差。


## 隐私与安全

请勿向 Issue、Pull Request 或仓库提交真实患者、客户或其他个人的 STL、PLY、DPLAN、截图、文件名或结果数据。提交问题时请使用 `scripts/create_demo_data.py` 生成的合成数据复现。
本地日志会记录输入文件名和路径，分享结果目录前请检查并移除可能识别个人身份的信息。
